# Uitjes en planning

Deze categorie gebruikt de bestaande centrale Settings Manager, revisies,
validatie en synchronisatie. Voorkeuren geven nooit extra apparaatrechten.

| Instelling | Daadwerkelijke werking |
|---|---|
| Ingeschakeld | Zet deze gespreksroute aan/uit |
| Samen / automatisch / verrassing / budget / ontspannen / gedetailleerd | Stuurt het voorstel; automatisch/verrassing kan een alternatief kiezen, ontspannen geeft ruimere pauzes |
| Standaardbudget | Voorlopig totaalbudget als de gebruiker er geen noemt; 0 is onbekend |
| Maximale afstand/reistijd | Contextvoorwaarde en waarschuwing bij overschrijding van opgegeven waarden; geen verzonnen routefilter |
| Vervoer | Voorlopige voorkeur, vervangen door expliciete keuze |
| Favorieten en deelnemersvoorkeuren | Bron-gelabelde context voor voorstellen |
| Duur | Voorlopige duur waar geen gebruikersduur beschikbaar is |
| Binnen/buiten | Filtert getoonde alternatieven |
| Weer meenemen | Stuurt een binnenalternatief bij gemelde regen; geen live weerkoppeling |
| Agenda meenemen | Gebruikt bestaande geautoriseerde CalendarRead; fouten blijven onbekend |
| Reistijd meenemen | Neemt opgegeven reistijd op en meldt ontbrekende ritten |
| Kosten berekenen | Toont bekende deelsom, per persoon waar bekend, budgetwaarschuwing en open kosten |
| Restaurants voorstellen | Staat gegenereerde eetvoorstellen toe; expliciete gebruikerswensen blijven behouden |
| Aantal alternatieven | Begrensd op twee tot vier |
| Initiatief | Overleggen of een gegenereerde optie als voorstel kiezen |
| Vragen | Alleen essentieel of maximaal twee samenhangende vragen in de generatie |
| Herinneringen | Neemt de bestaande agenda-herinneringsvoorkeur op in het exacte schrijfvoorstel |
| Communicatie | Alleen Gmail-concept of ook bestaande verzendpreview voorbereiden; versturen vereist approval |
| Zoekintegraties | Momenteel geen beschikbare geregistreerde adapter; geen live zoekactie |

Deelnemersvoorkeuren invoeren als één `naam: voorkeur` per regel. Favorieten
invoeren als één activiteit per regel. Bestaande geheugen-/privacy-instellingen
bepalen of context duurzaam wordt bewaard en met een cloudprovider mag worden
gedeeld. ‘Zonder geschiedenis’ bewaart de actieve planning alleen tijdelijk in RAM.
