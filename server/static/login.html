Eerst je eigenaaraccount instellen

Open PowerShell in de projectmap. Stop de server en maak lokaal je account aan:

powershell.exe -NoProfile -File scripts/Stop-Server.ps1
.\.venv\Scripts\python.exe -m server setup-owner
powershell.exe -NoProfile -File scripts/Start-Server.ps1 -Background

Je kiest je wachtwoord zelf in de terminal. Herlaad daarna deze pagina.

Je geschiedenis blijft lokaal opgeslagen. Dit apparaat wordt na inloggen geregistreerd.
